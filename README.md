# 🎬 Movie Recommendation System

[![CI](https://github.com/YOUR-USERNAME/movie-recommender-system/actions/workflows/ci.yml/badge.svg)](https://github.com/YOUR-USERNAME/movie-recommender-system/actions)
![Python](https://img.shields.io/badge/python-3.10%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

A command-line movie recommender that combines **content-based filtering** (TF-IDF on genres and keywords) with **item-based collaborative filtering** (cosine similarity on user ratings) into a **hybrid** model.

Integrated M.Tech AI, VIT Bhopal University
**Course project:** VITyarthi

---

## Features

- **Personalised recommendations** for any existing user (`recommend`)
- **Similar movies** to any title, with partial and case-insensitive matching (`similar`)
- **Popular movies** ranked by average rating (`popular`)
- **Interactive mode** where a new user rates a few movies and gets recommendations (`interactive`) - this handles the cold-start case
- **Offline evaluation** with RMSE, MAE and Precision@5 against a held-out split (`evaluate`)
- Adjustable blend between collaborative and content scores (`--alpha`)
- 16 unit tests and a GitHub Actions CI workflow

## How it works

| Method | Idea |
|---|---|
| Content-based | Each movie becomes a TF-IDF vector from its genres and keywords. Movies with similar vectors (cosine similarity) are recommended together. |
| Collaborative | Ratings are mean-centred per user, then item-item cosine similarity predicts a user's rating for an unseen movie from movies they already rated. |
| Hybrid | Both score sets are min-max normalised and blended: `alpha * collaborative + (1 - alpha) * content`. Default `alpha = 0.6`. |

## Usage

```bash
python -m movie_recommender recommend --user 1 --n 5
python -m movie_recommender similar --title "Inception"
python -m movie_recommender popular
python -m movie_recommender evaluate
python -m movie_recommender interactive
python -m movie_recommender --alpha 0.3 recommend --user 4   # more content-based
```

### Use as a library

```python
from movie_recommender import load_data, HybridRecommender

movies, ratings = load_data()
rec = HybridRecommender(movies, ratings, alpha=0.6)
print(rec.recommend(user_id=1, n=5))
print(rec.recommend_from_ratings({16: 5, 18: 5, 24: 4}, n=3))  # new user
```

## Evaluation results

Run with `python -m movie_recommender evaluate` (80/20 per-user split, seed 42):

| Metric | Item-based CF | Global-mean baseline |
|---|---|---|
| RMSE | **0.880** | 1.126 |
| MAE | 0.714 | - |
| Precision@5 | 0.067 | - |

The collaborative model cuts RMSE by about 22% versus always predicting the average rating. Precision@5 is low because each user has only about 3 held-out ratings, so very few relevant items exist to be found. See the report for details.

## Dataset note

The ratings are **synthetic**, generated by `data/generate_ratings.py` from five genre-taste profiles plus noise. This keeps the repository small and fully reproducible. To use real data, replace the two CSV files with the same columns (for example a MovieLens subset mapped to this format).
